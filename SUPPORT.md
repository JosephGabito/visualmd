# Visual MD support

For setup help, unexpected behavior, or a question about using Visual MD,
visit the [support page](https://visualmd.gabi.to/support/). A reproducible bug
can be reported with the repository's bug form.

Please do not attach a private Markdown library. Reduce the problem to the
smallest safe example, and remove file paths, credentials, and personal
information before sharing logs or screenshots.

Suspected vulnerabilities belong in the private process described in
[SECURITY.md](SECURITY.md), not in a public issue.
